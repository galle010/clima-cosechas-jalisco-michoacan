# clima-cosechas-jalisco-michoacan
Dataset con la informacion climatica de los 238 municipios que conforman a Jalisco y  a Michoacan, con las siguientes caracteristicas: cvegeo, estado, municipio, anio, idciclo, ciclo, t_max_prom, t_media_prom, t_min_prom, t_max_abs, t_min_abs, dias_calor, dias_helada, lluvia_total_mm, dias_lluvia, humedad_prom, viento_prom, radiacion_prom
